# Roles

- `super_admin` — full administration
- `reservations_manager` — reservation administration foundation
- `finance_manager` — financial administration foundation
- `tour_manager` — tour/product administration foundation
- `property_owner` — supplier/property foundation
- `hotel_partner` — supplier foundation
- `activity_provider` — supplier foundation
- `driver` — supplier foundation
- `tour_guide` — supplier foundation
- `travel_agent` — future B2B foundation
- `customer` — customer resources

Server-side authorization is required; frontend visibility is not a security boundary.
