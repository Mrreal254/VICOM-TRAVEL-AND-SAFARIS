# VICOM TRAVEL & SAFARIS

**Discover Kenya. Experience Africa.**

Phase 1 foundation for a modern Kenyan travel and tourism marketplace.

## Repository boundary

This project is independent of `vicom-enterprise-mpesa`. Do not copy or modify M-Pesa application code as part of this project.

## Structure

- `frontend/` — Next.js + React + TypeScript + Tailwind
- `backend/` — Laravel REST API + PostgreSQL
- `docs/` — architecture, database, API and setup documentation

## Phase 1 scope

Authentication, roles, customer profiles, suppliers, destinations, media foundation, settings, audit logs, public APIs, admin APIs, and initial public/customer/admin UI.
